# Trigger Codes (MoveDot1_experiment_occlusion_v25_dotOffsetBlank)

| Code / Range | Short label | Extended description |
| --- | --- | --- |
| 71 | Trial onset (always_visible) | First frame of an `always_visible` trial. |
| 81 | Trial onset (occluded_nondeviant) | First frame of an `occluded_nondeviant` trial. |
| 91 | Trial onset (occluded_deviant) | First frame of an `occluded_deviant` trial. |
| 1..N | Trial sequence identity | Emitted once at fixed frame offset (`Conf.sequenceIdentityTriggerFrame`, default 12). Value equals `xySeqs(source_index).sequence`. |
| 111 | Occlusion start | First frame where occlusion starts (`occlusion_start_frame`). |
| 112 | Occlusion complete | First frame where the dot is fully hidden (`occlusion_complete_frame`). |
| 114 | Occlusion end start | First frame where the dot starts reappearing (`occlusion_end_frame`). |
| 115 | Occlusion end complete | First frame where the dot is fully visible again (`occlusion_end_complete_frame`). |
| 116 | Catch type-1 disappear | Type-1 catch only: first frame where dot disappears in run 1. |
| 117 | Catch type-1 reappear | Type-1 catch only: first frame where dot reappears in run 1. |
| 118 | Catch question start | First frame of catch question prompt. |
| 201 | Catch question end: correct | Catch question closed with a scored correct response. |
| 202 | Catch question end: incorrect | Catch question closed with a scored incorrect response (or unscorable non-timeout response). |
| 113 | Catch question end: timeout | Catch question closed because no response arrived before timeout. |
| 150 | Gaze break | Emitted when fixation leaves the acceptance window for `fixBreakToleranceFrames` consecutive frames. |
| 151 | Replay start | Emitted once per run immediately before the first replayed trial starts after at least one gaze break. |
| 152 | ESC termination | Dedicated termination event emitted when the session ends because ESC was pressed (during block or at end-of-block gate). |
| 153 | Scheduled-onset warm-up | Diagnostic marker emitted for each of the ten default session warm-up cycles before the first retained trial. Not a participant trial. |

## Notes

- This map is defined by `experiment/MoveDot1_experiment_occlusion_v25_dotOffsetBlank.m`.
- Runtime validates that dynamic sequence trigger range `1..N` does not overlap fixed codes or warm-up code `153`.
- In the V30/v23/v25 stack, `N` is typically `40` because `trialsPerCondition = 40`.
- Catch-question close events are mutually exclusive: each catch emits exactly one end-status trigger (`201`, `202`, or `113`).
- Catch planning is generated by `experiment/CreateInputFiles_v23_rescueTraject.m`.
- Eye-tracker EDF policy is one file per block (`per_block`), and each block EDF is received before the between-block rest/continue screen whenever real EyeLink acquisition is active (`Conf.useEyelink`).
- Standardized ESC logs in the runtime are:
  - `esc pressed during block [block_number]`
  - `esc pressed at the end of block [block_number]`

## Photodiode, scheduled-onset, and dot-offset policy (v25)

- Condition codes `71`, `81`, and `91` are emitted after the complete first
  trial frame is drawn. The existing time-based DOUT schedule is committed,
  the four-frame trial pulse is armed, the patch is drawn last, and the
  target frame is flipped from the preceding VBL using measured PTB `ifi`.
- For the first trial of each run, v25 retains the v24 behavior of rendering frame 1 into the back
  buffer and erases it with the ordinary fixation baseline without flipping,
  emitting a trigger, or raising the patch. This invisible renderer preflight
  remains run-boundary-only.
- Immediately before every retained `71`, `81`, or `91`, the all-trial guard
  requires at least `3 ms` before the requested flip deadline. A failed lead
  check emits neither condition trigger nor photodiode pulse, presents one
  additional low-patch fixation frame, redraws frame 1, and retries. At most
  six rollover frames are allowed. Exhaustion is recorded and the latest
  attempt continues instead of aborting acquisition.
- The preceding randomized ITI is presented as consecutive scheduled
  fixation frames and supplies the reference VBL without adding a separate
  pre-onset delay. Its requested duration is quantized to the nearest whole
  measured-IFI frame, and both requested and realized durations are saved.
- Before the first retained trial of each experiment launch, ten default
  code-153 warm-up cycles exercise the same time-based DOUT, four-high-frame
  patch, explicit-low-return, and scheduled-flip path. At 120 Hz the marked
  cycles take approximately `0.42 s`; they are excluded from trial analysis.
- Visual event codes `111`, `112`, `114`, `115`, `116`, `117`, and `118`
  use `photodiodeEventPulseFrames` (default: two frames).
- Catch-question onset `118` retains the v21 unscheduled question-onset
  implementation; it remains outside the v25 trial-onset
  scheduling scope.
- Dot disappearance at the end of a motion epoch emits no new digital trigger
  and starts no high photodiode pulse. V25 schedules a fixation-only,
  low-patch flip on the VBL immediately after the final retained motion frame,
  before EyeLink or next-trial preparation. Saved `dot_offset_*` timestamps
  provide PTB-side verification; `trial_end_time` remains the final motion VBL.
- Sequence identity, catch-question end status, gaze/replay, and ESC codes do
  not start a photodiode pulse.
- Patch enablement, size, position, and high/low colors are set in
  `experiment/lib/Config_runtime_v25_dotOffsetBlank.m`. The patch
  is drawn last before every experiment-controlled flip and remains low
  outside the marked pulses.
- The integrated v23 audit measured 95 condition onsets at
  `18.747 +/- 0.635 ms`; excluding one objectively late-armed non-boundary
  event gave `18.798 +/- 0.404 ms` over 94 events. The valid v24 replacement
  audit then measured 433 condition onsets at `18.76 +/- 0.47 ms`, with 14
  rollover frames across seven trials and no guard exhaustion. V25 retains
  that onset path unchanged; its newly added dot-offset flip still requires a
  short participant-display check before acquisition.
