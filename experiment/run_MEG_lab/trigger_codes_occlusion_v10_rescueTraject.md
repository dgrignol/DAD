# Trigger Codes (MoveDot1_experiment_occlusion_v21_photodiode)

| Code / Range | Short label | Extended description |
| --- | --- | --- |
| 71 | Trial onset (always_visible) | First frame of an `always_visible` trial. |
| 81 | Trial onset (occluded_nondeviant) | First frame of an `occluded_nondeviant` trial. |
| 91 | Trial onset (occluded_deviant) | First frame of an `occluded_deviant` trial. |
| 1..N | Trial sequence identity | Emitted once at fixed frame offset (`Conf.sequenceIdentityTriggerFrame`, default 12). Value equals `xySeqs(source_index).sequence`. |
| 111 | Occlusion start | First frame where occlusion starts (`occlusion_start_frame`). |
| 112 | Occlusion complete | First frame where the dot is fully hidden (`occlusion_complete_frame`). |
| 114 | Occlusion end start | First frame where the dot starts reappearing (`occlusion_end_frame`). |
| 115 | Occlusion end complete | First frame where the dot is fully visible again (`occlusion_end_complete_frame`). |
| 116 | Catch type-1 disappear | Type-1 catch only: first frame where dot disappears in run 1. |
| 117 | Catch type-1 reappear | Type-1 catch only: first frame where dot reappears in run 1. |
| 118 | Catch question start | First frame of catch question prompt. |
| 201 | Catch question end: correct | Catch question closed with a scored correct response. |
| 202 | Catch question end: incorrect | Catch question closed with a scored incorrect response (or unscorable non-timeout response). |
| 113 | Catch question end: timeout | Catch question closed because no response arrived before timeout. |
| 150 | Gaze break | Emitted when fixation leaves the acceptance window for `fixBreakToleranceFrames` consecutive frames. |
| 151 | Replay start | Emitted once per run immediately before the first replayed trial starts after at least one gaze break. |
| 152 | ESC termination | Dedicated termination event emitted when the session ends because ESC was pressed (during block or at end-of-block gate). |

## Notes

- This map is defined by `experiment/MoveDot1_experiment_occlusion_v21_photodiode.m`.
- Runtime validates that dynamic sequence trigger range `1..N` does not overlap fixed codes.
- In the V30/v23/v21 stack, `N` is typically `40` because `trialsPerCondition = 40`.
- Catch-question close events are mutually exclusive: each catch emits exactly one end-status trigger (`201`, `202`, or `113`).
- Catch planning is generated by `experiment/CreateInputFiles_v23_rescueTraject.m`.
- Eye-tracker EDF policy is one file per block (`per_block`), and each block EDF is received before the between-block rest/continue screen whenever real EyeLink acquisition is active (`Conf.useEyelink`).
- Standardized ESC logs in the runtime are:
  - `esc pressed during block [block_number]`
  - `esc pressed at the end of block [block_number]`

## Photodiode marker policy (v21)

- Condition codes `71`, `81`, and `91` are emitted after the first trial
  frame is fully drawn and immediately before the patch draw and display
  flip. They use `photodiodeTrialPulseFrames` (default: four frames).
- Visual event codes `111`, `112`, `114`, `115`, `116`, `117`, and `118`
  use `photodiodeEventPulseFrames` (default: two frames).
- Sequence identity, catch-question end status, gaze/replay, and ESC codes do
  not start a photodiode pulse.
- Patch enablement, size, position, and high/low colors are set in
  `experiment/lib/Config_runtime_v21_photodiode.m`. The patch
  is drawn last before every experiment-controlled flip and remains low
  outside the marked pulses.
